# Browser fallback для динамических карточек

Использовать интерактивный браузер только как второй слой проверки уже найденной точной карточки. Не заменять им веб-поиск по всему каталогу.

## Когда запускать

Запустить browser fallback, если выполняется хотя бы одно условие:

- карточка показывает диапазон цен, а точная цена появляется после выбора цвета, памяти, размера, комплектации или продавца;
- цена или наличие зависят от города и не видны без выбора региона;
- текстовый экстракт видит товар и варианты, но не видит цену либо кнопку покупки;
- обычный HTTP-доступ получает 401/403 или пустую оболочку, а карточка штатно открывается в браузере пользователя;
- индекс и карточка расходятся, и интерактивная проверка может разрешить противоречие.

Не запускать браузер только ради повторения уже подтверждённой статической цены.

## Как проверять

1. Убедиться, что доступен настоящий браузерный движок. Обычное открытие URL через текстовый web fetch не считать браузерной проверкой.
2. Открыть прямую ссылку на конкретную карточку. Не начинать новый широкий поиск внутри магазина.
3. Выбрать город из профиля покупателя, затем точный вариант: модель, состояние, память, цвет, SIM-версию, размер, комплект и продавца. Не подменять отсутствующий вариант ближайшим.
4. Дождаться завершения обновления страницы. Считать доказательством только видимые после выбора данные: название варианта, цена, наличие, продавец и обязательные условия скидки.
5. Сверить изменившийся URL, артикул, MPN или иной идентификатор, если сайт их показывает. Зафиксировать прямую ссылку и выбранные параметры.
6. Присвоить `verified-card`, только если браузер одновременно показывает точный выбранный вариант и его цену. Если вариант или цена остались неоднозначными, использовать `unverified` либо `stale-risk`.

Если в агентской среде нет готового browser tool, использовать локальный Chrome через [browser_probe.mjs](../scripts/browser_probe.mjs). Скрипт не требует claude.ai, расширения браузера, Playwright или Puppeteer: он запускает Chrome с новым временным профилем и управляет вкладкой через Chrome DevTools Protocol.

Сначала прочитать карточку без действий:

```bash
node scripts/browser_probe.mjs --url 'https://example-shop.ru/product/...'
```

Если нужный вариант не представлен видимым текстом, повторить чтение с `--controls --text-limit 5000` и использовать только штатный элемент из поля `controls`; не выполнять произвольный код страницы.

Затем повторить проверку с нужными вариантами в порядке, в котором они выбираются на странице:

```bash
node scripts/browser_probe.mjs --url 'https://example-shop.ru/product/...' \
  --click 'Чёрный' --click '128 ГБ'
```

Считать действия успешными только при `ok: true`, `challenge: false`, `blocked: false` и `found: true` у каждого элемента `actions`. Сопоставить `visibleText`, `prices`, итоговый `url` и название карточки с точным вариантом. Headless Chrome остаётся настоящим JS-браузером; если сайт различает headless-режим, допустимо повторить команду с `--headed` после разрешения пользователя на запуск GUI. При этом также используется отдельный временный профиль без cookies основного Chrome.

## Ограничения и безопасность

- Проверять не более 1–2 финальных карточек за обычный запрос.
- Не добавлять товар в корзину, не переходить к оформлению, не входить в аккаунт и не менять профиль покупателя ради получения цены.
- Допустимо выбрать регион и вариант товара, если это необходимо для чтения карточки.
- При CAPTCHA или запросе входа остановиться. В интерактивной сессии попросить пользователя выполнить CAPTCHA или вход вручную; не обходить защиту и не переносить cookies в скрипты.
- Не использовать внутренние API, найденные в DevTools, как обход штатного интерфейса.
- Не сохранять screenshots, cookies, токены или данные аккаунта без отдельной просьбы пользователя.
- Не подключаться к уже запущенному пользовательскому профилю Chrome. Использовать временный профиль, создаваемый `browser_probe.mjs`; не передавать ему путь к основному профилю.
- Ошибка browser fallback на одном домене не должна останавливать поиск по остальным источникам.
