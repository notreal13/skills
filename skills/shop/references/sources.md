# Источники и стратегия доступа

Использовать этот файл как маршрутизатор поиска, а не как гарантию текущей доступности сайта. Поведение магазинов, индексация и антибот меняются; проверять их в текущем запросе.

## Общая стратегия

1. Начинать с веб-поиска по точной модели или идентификатору.
2. Добавлять домен через запрос вида `site:example.ru "точная модель"`, если общий поиск даёт шум.
3. Открывать только наиболее перспективные карточки для проверки варианта, цены, продавца и наличия.
4. Использовать прямой поиск магазина только если он доступен без обхода защит.
5. При CAPTCHA, 403, бесконечной загрузке или антиботе остановиться после первой попытки. Сохранить индексированный результат с соответствующим статусом и перейти к другим источникам.

Для точного товара полезны запросы:

- `"бренд модель конфигурация" купить`;
- `"MPN" цена`;
- `"EAN или ISBN"`;
- `site:домен "бренд модель"`;
- `site:домен "MPN"`.

Не использовать поисковую выдачу как доказательство наличия. Не собирать результаты с агрегаторов, если нельзя установить исходный магазин и конкретный вариант товара.

| Яндекс Маркет | Искать модель и карточки через индекс; учитывать региональную выдачу | Конкретный продавец, регион, доставка, гарантия |
| Мегамаркет | Использовать как дополнительный индексируемый источник | Продавец, бонусная часть цены, условия скидки |

Не предполагать наличие публичного покупательского API у маркетплейса только потому, что у него есть API для продавцов или партнёров.

| Электроника и бытовая техника | DNS, Ситилинк, М.Видео, Эльдорадо, Ozon, Яндекс Маркет | У сетей цены и наличие часто региональны; индексировать сначала, затем открывать карточку |
| Компьютеры и компоненты | DNS, Ситилинк, Регард, XCOM, Ozon, Яндекс Маркет | Сопоставлять точный MPN, ревизию и комплектацию |

| Одежда и обувь | Lamoda, Спортмастер, Brandshop, Sneakerhead, Wildberries, Ozon | Размер и цвет считать частью варианта; некоторые каталоги удобнее находить через индекс |
| Косметика и парфюмерия | Золотое Яблоко, Рив Гош, Randewoo, Иль де Ботэ, Ozon | Высокий риск смешения объёма и концентрации; проверять продавца и партию |

## Когда карточка недоступна

- Сохранить прямую индексированную ссылку, только если она ведёт на конкретный товар.
- Пометить цену как `indexed` или `stale-risk`.
- Не утверждать наличие, продавца и окончательную цену, если их нет в сниппете.
- Дать покупателю короткий список полей для ручной проверки, не перекладывая на него весь поиск.
